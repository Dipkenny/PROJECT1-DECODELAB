# PROJECT1-DECODELAB
# Preparing a Retail Dataset for Analysis.

Here are what I did:

* Data inspection: Identified 1,200 records in the dataset.

* Duplicate check: Used the "OrderID" column to investigate duplicate records and found none.

* Data types: Reviewed and assigned appropriate data types to support accurate analysis. I deliberately kept the "UnitPrice" and "TotalPrice" columns as numbers rather than currency because the available dataset did not provide enough information to determine the appropriate currency.

* Missing values investigation: Discovered 309 missing values in the "CouponCode" column. Rather than immediately replacing them, I decided to investigate why the values are missing before taking action.
